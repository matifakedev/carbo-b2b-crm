# CARBO B2B CRM

Vamos a diseñar un CRM con foco en B2B para una empresa de venta de baterias industriales con foco en grandes clientes.
Vamos a armar el proyecto por etapas, yo te ire dando los prompts para ir armandolo. 
El nombre debe ser CRM - CARBO y te dejo una carpeta con la estetica de la marca para que la uses en el diseño.

This project was built with [Lovable](https://lovable.dev).
